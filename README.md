# AI Bot City Simulator — Smallville (frontend-only)

A living isometric city of autonomous agents. No backend, no database server, no account, no API key, no external AI. Simulation, memories, and persistence all run locally in the browser.

## Commands
```bash
npm install
npm run dev      # start, usually http://localhost:5173
npm run build    # typecheck + production build
npm run preview  # serve the production build
npm test         # Vitest unit tests
npm run test:e2e # Playwright (requires browsers: npx playwright install chromium)
```

## What is implemented
- Phaser 3 isometric city: Smallville with Neural Cafe, Central Park, Residential District, Town Hall, Corner Shop, Office Building, Restaurant, Bus Stop; roads, crosswalks, sidewalks, trees, benches, streetlights, parked vehicles (drawn procedurally, no remote images).
- 24 seeded distinct agents with roles, personalities, needs (energy/hunger/mood/sociability/confidence), schedules, relationships, and memories.
- Real engine in `src/simulation/`: Perceive → needs → utility goal selection → A* pathfinding on walkable tiles only → movement → proximity interaction → event + memory. States: Idle, Walking, Commuting, Working, Eating, Resting, Socializing, Shopping, Waiting, Sleeping, Conversing.
- Dashboard: top bar (pause, 1x/2x/4x/8x, Add Agent, tick, time), Agent Registry (search/filter/sort), live Metrics computed from state, Agent Inspector (follow, memories, relationships, pause/reset agent, personality slider), collapsible Event Console (search/filter, autoscroll, clear), and views City / Agents / Locations / Memories / Event Log / Settings that do not destroy the simulation (Phaser stays mounted, hidden, when another view is shown).
- Persistence: Dexie IndexedDB + localStorage, Zod-validated snapshots, Save/Load/Reset. Corrupt saves are rejected with a message, not loaded.
- Optional browser-local LLM: defined as off by default only in the sense that the rules engine is the sole decision loop; no LLM code path, download, or external call exists in this build. Conversation summaries are generated by local rules and are never described as LLM output.

## Limitations
- The city is pseudo-isometric (diamond tiles + raised blocks), not a full 3D or hand-drawn pixel-art sprite sheet; agent sprites are coloured procedural shapes, not individual pixel-art frames.
- Canvas click hit-testing selects the nearest agent container in Phaser; precise pixel hit-testing is not implemented.
- Playwright e2e requires a browser download and was not run in the offline verification pass if that download is unavailable (see test results in the delivery report).
- Save/Load restores agents, memories, events, tick, and seed, but Phaser camera position is not persisted.
